## 资源内容

- **802.11a**: 基于5 GHz频段的无线局域网标准。
- **802.11b**: 基于2.4 GHz频段的无线局域网标准，提供更高的数据传输速率。
- **802.11d**: 用于国际漫游的无线局域网标准。
- **802.11e**: 增强型无线局域网标准，支持服务质量（QoS）。
- **802.11h**: 用于5 GHz频段的无线局域网标准，支持动态频率选择（DFS）和传输功率控制（TPC）。
- **802.11j**: 适用于日本的无线局域网标准。
- **802.11k**: 无线资源管理标准，优化无线网络性能。
- **802.11s**: 无线网状网络标准。
- **802.11n**: 高吞吐量无线局域网标准，支持多输入多输出（MIMO）技术。
- **802.11v**: 无线网络管理标准，优化无线网络操作。
- **802.11w**: 无线局域网保护管理帧标准。
- **802.11y**: 基于3.7 GHz频段的无线局域网标准。
- **802.11ac**: 高吞吐量无线局域网标准，支持更宽的信道带宽和更高的数据速率。
- **802.11ad**: 基于60 GHz频段的无线局域网标准，提供极高的数据传输速率。
- **802.11ax**: 下一代无线局域网标准，支持更高的网络容量和效率。
